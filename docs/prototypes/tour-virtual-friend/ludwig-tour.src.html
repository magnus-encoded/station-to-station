Keyboard spec

Where the keyboard comes up

S3 and S4 (band, venue and date fields), S14 (the Log's song field) and S15, which can begin with the keyboard still up because Add does not dismiss it. The strip's a and b chips are the keyboard-shown and keyboard-hidden states of those steps.

Rules

S3 and S4: the card is laid out inline above the form fields on both platforms, keyboard up or down. S14 and S15: bottom overlay while the keyboard is down; docked to the top while it is up. The card is never behind the keyboard and never over a field the user is typing in.

Not a script concern

Keyboard shown and hidden are UI events. They are not TourEvents and the state machine and frozen fixtures do not see them. Android: WindowInsets.isImeVisible. iOS: the keyboard will-show and will-hide notifications.
